In this first attempt at designing a Programmable Logic Device (PLD) circuit, there is a 4 bit counter, data input storage, the core executer, and a final storage zone. The storage is made of 10 8 bit parallel serial input shift registers, and they are either programmed by hand or by the PLD software. The first bit of the 4 bit counter is used to save the output of the core executer for use in subsequent executions. The other three bits in the 4-bit counter connects to multiplexers which select which data to get out of storage. The output of the multiplexers are connected to the execution core, where the stored data is interpreted and converted into an AOI action. Finally, the output of the execution core is saved to an 8 bit parallel serial input shift register. This would have been connected back to one of the inputs so the program can choose to use a past AOI execution in a future execution. 

The circuit is incomplete and won't work. Even what is pictured isn't fully tested as a better design was developed before the development of this circuit was completed.
