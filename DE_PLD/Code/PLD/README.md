This folder contains all of the python scripts that are necessary to program the PLD circuit. The program dynamically creates an Arduino sketch which is uploaded to an Arduino in the cable that connects the computer to the circuit. The Arduino then sends out the necessary clock and data signals to set the program into the circuit. The software also has two quality of life features to make programming the circuit easier. The first is the ability to save and load past programs. The second is the ability to test a program before uplaoding it to the circuit, with digital buttons and a truth table.
